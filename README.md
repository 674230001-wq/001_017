## 🗄️ โครงสร้างฐานข้อมูล (Database)
- **ชื่อฐานข้อมูล MySQL:** `porsche_repair_db`
- **ไฟล์ SQL สำรองพร้อมข้อมูลตัวอย่าง (SQL Dump):**
  - [`database/porsche_repair_db.sql`](file:///c:/xampp/htdocs/001/database/porsche_repair_db.sql)
  *(มีตาราง, Foreign Keys, และข้อมูลตัวอย่างเคสจริงครบถ้วน สามารถนำไป Import ผ่าน phpMyAdmin ได้ทันที)*

### ตารางหลักในระบบ (Core Tables):
1. `users` - เก็บข้อมูลผู้ใช้งาน (Admin, Technician, Customer) พร้อมความเชี่ยวชาญของช่าง
2. `porsche_models` - แคตตาล็อกรุ่นรถยนต์ Porsche (911 GT3 RS, Taycan, Cayenne, Macan, 718 Cayman, Panamera)
3. `service_catalogs` - รายการอะไหล่แท้และอัตราค่าแรงมาตรฐานศูนย์ (เช่น เบรก PCCB, แบตเตอรี่ EV, น้ำมันเกียร์ PDK)
4. `repairs` - ข้อมูลใบแจ้งซ่อม, อาการ, ข้อมูลรถ, สถานะ, ผลตรวจสภาพ, ยอดประเมิน และการอนุมัติ
5. `repair_items` - รายการแจกแจงอะไหล่และค่าแรงในใบประเมินราคา
6. `repair_images` - รูปภาพแนบ (ภาพอาการจากลูกค้า, ภาพการตรวจเช็คของช่าง, ภาพหลังซ่อมเสร็จ)
7. `repair_logs` - ไทม์ไลน์บันทึกประวัติการเปลี่ยนสถานะและเวลาแบบเรียลไทม์

## 🚀 ฟังก์ชันเด่นและลูกเล่นในระบบ (Key Features & Highlights)

1. **ระบบติดตามสถานะงานซ่อมแบบรวดเร็ว (Quick Public Tracking):**
   - ค้นหาสถานะได้ทันทีด้วยเลขที่ใบแจ้งซ่อม (เช่น `POR-2026-0001`) หรือเลขทะเบียนรถ โดยไม่ต้องล็อกอิน
2. **แถบความคืบหน้า 6 สเต็ป (Visual Progress Stepper):**
   - 1. รับเรื่องแจ้งซ่อม &rarr; 2. มอบหมายช่าง &rarr; 3. ตรวจเช็คสภาพ &rarr; 4. ประเมินราคา &rarr; 5. กำลังซ่อม &rarr; 6. ซ่อมเสร็จส่งมอบ
3. **แบบฟอร์มแจ้งซ่อมพร้อมลูกเล่นสำหรับลูกค้า:**
   - เลือกรุ่นรถยนต์ Porsche พร้อมแสดงรายละเอียดเครื่องยนต์
   - ปุ่มสุ่มตัวอย่างเลขตัวถัง (Sample Porsche VIN Generator) เพื่อความสะดวกในการกรอก
   - ระบบอัปโหลดรูปภาพหลายรูปพร้อมแสดงรูปตัวอย่าง (Live Thumbnail Preview)
4. **ห้องปฏิบัติการช่างเทคนิค (Technician Workstation):**
   - แบบฟอร์มตรวจสภาพ 111 จุด (ระบบเบรก, ยาง, แบตเตอรี่ 800V, ของเหลว, ช่วงล่าง PASM)
   - ช่องบันทึกรหัสข้อผิดพลาดจากเครื่องคอมพิวเตอร์วินิจฉัย PIWIS-3
   - เครื่องมือจัดทำใบเสนอราคา ดึงราคาจากแคตตาล็อกอะไหล่แท้อัตโนมัติ หรือพิมพ์เองได้
   - คำนวณภาษีมูลค่าเพิ่ม (VAT 7%) และส่วนลดอัตโนมัติ
   - ช่างสามารถถ่ายรูปอัปโหลดผลการตรวจสภาพหรือรูปรถหลังซ่อมเสร็จได้
5. **ระบบอนุมัติใบเสนอราคา (Quotation Approval Flow):**
   - ลูกค้าสามารถตรวจสอบรายการอะไหล่และกดยืนยัน **"อนุมัติการซ่อม"** หรือ **"ขอระงับการซ่อม"** ได้จากหน้าเว็บ
6. **การประเมินความพึงพอใจ (Rating & Review):**
   - หลังซ่อมเสร็จ ลูกค้าสามารถให้คะแนนดาว 1-5 ดาว พร้อมข้อเสนอแนะ
7. **แดชบอร์ดผู้บริหาร (Executive Admin Dashboard):**
   - การ์ดสรุปยอดงานซ่อม ยอดกำลังดำเนินการ และยอดรายได้รวม
   - กราฟโดนัท (Doughnut Chart) แสดงสัดส่วนรุ่นรถยนต์ที่เข้ารับบริการ (Chart.js)
   - กราฟแท่ง (Bar Chart) แสดงภาระงานของช่างแต่ละคน
8. **ใบสั่งซ่อมและใบเสนอราคาทางการ (Official Printable Sheet):**
   - หน้าเอกสารทางการมาตรฐาน A4 พร้อมหัวเอกสารศูนย์บริการ ตารางแจกแจงค่าใช้จ่าย และช่องลงนาม 3 ฝ่าย (ลูกค้า, ช่างธนศักดิ์, แอดมินรภิภัทร)
